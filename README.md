# Fidenaut

**Fidenaut — Trustworthy autonomy through verifiable governance.**

Fidenaut is an independent extracted project containing a governed AI-assisted software-development workflow for bounded delegated autonomy. The workflow was originally developed inside [ChessEcho](https://github.com/NathanZK/ChessEcho), which is the originating project and canonical/reference first consumer.

Fidenaut was extracted in September 2026 and did not exist as an independent project before this extraction. Future projects may consume Fidenaut at explicit, verifiable revisions.

This project preserves bounded authority, observable execution, verifiable evidence, independent adversarial verification, and fail-closed recovery as engineering goals, not safety guarantees. Self-attested local approvals remain distinct from independent human authorization, and role strings remain distinct from authenticated actor identity.
